## Идея Компании

Наша бизнес-идея - это онлайн-консултант для молодых предпринимателей, который хотят создать свой бизнес или для владельцев бизнеса малого или среднего сегмента. Калькулятор стоимости создания бизнеса высчитывает издержки, прибыль и другие показатели взависимости от выбранных категорий пользователем, основываясь на данных в открытом доступе (данные обновляются с помощью ML-алгоритмов). Данный продукт представлен в виде вебсайтах и мобильного приложения, где можно оплатить расширенную версию.
