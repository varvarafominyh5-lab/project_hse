# Идея Компании

Наша бизнес-идея - это онлайн-консултант для молодых предпринимателей, который хотят создать свой бизнес или для владельцев бизнеса малого или среднего бизнеса. Калькулятор стоимости создания бизнеса высчитывает издержки, прибыль и другие показатели взависимости от выбранных категорий пользователем.
